# Batch MCP-U1 — builder notes from the MCP-A1 build (2026-11-08)

Status: REFERENCE for whoever builds Batch MCP-U1 (wording: `plan/architect/BATCH_MCP_PHASE1_2026-11-07.md`, Part 3; queue section added by PR #58). Written by Claude after building MCP-A1 (PR #58). These are findings from reading uclrcde `main` @ 201f0319, not new wording; where they need a ruling, the builder says so in its pull request (uclrcde AGENTS.md rule 13).

1. **Public or case file?** `source_documents` has no data-class column. Recommended reading: a document counts as PUBLIC_LAW only if it has a `source_provenance` row (judgments, A2AJ) or an `official_law_provenance` row (federal Acts) **and** no `document_cards` row with `private_flag != 0`. Anything else is refused as possible CASE_FILE data. Deny by default.
2. **Paragraphs of public judgments.** `paragraph_anchors` belong to `document_cards` (case-file cards), so public judgments normally have none. Their paragraphs are the `[N]` markers in `raw_text` (`_MARKER_RE = r"\[(\d+)\]"` in `uclrcde_sources.py`). Paragraph N = the text after `[N]` up to the next marker. Needs an architect ruling, because the wording says "from paragraph_anchors or locked paragraph text".
3. **`verify_quote_in_passage` is defined twice** in `uclrcde_sources.py`. The later one (line ~782, LS-B, whole-word edges) is the live definition, and it raises `ValueError` on an empty quote.
4. **`check_section_in_force_on`** returns `IN_FORCE`, `NOT_YET_IN_FORCE`, `NO_LONGER_IN_FORCE` or `DATE_NOT_CHECKED`. Only `IN_FORCE` should pass MCP-U101; `DATE_NOT_CHECKED` is a REJECTED answer with its own reason.
5. **Test fixtures.** The provenance writers fetch from the network, so tests insert made-up provenance rows directly into the temporary database after `init_uclrcde_db_and_register_matter` and `ingest_and_lock_legal_source_document` (made-up text with `[1]`, `[2]` markers), and `record_law_section_dates` for in-force periods. `create_document_card` makes the private-card case.
6. **`KNOWN_COURT_CODES` and `find_canadian_citations`** (`uclrcde_oracle.py`): a match carries `status` `FORMAT_OK` or `MALFORMED`; MCP-U102 should require exactly one `FORMAT_OK` match covering the whole stripped input.
7. **Same dispatcher shape as MCP-A1** (`code/apccs_mcp.py` in apccs) keeps the doors identical: request dicts `{path, method, body | query, client_ip}`, response `{http_status, headers, body}`, Origin check, 60 requests per IP per hour, stateless 2026-07-28 headers. uclrcde must not import apccs code (AGENTS.md rule 6), so the shape is rewritten, not imported. Receipts go to the add-only `mcp_tool_receipts` table instead of a Log v2 chain.
8. **Pilot P-SG1.** MCP-A1 (PR #58) was the 5th pilot batch PR (Arm A), so MCP-U1's PR is the 6th: Arm B by alternation. Write the arm that was actually used.
