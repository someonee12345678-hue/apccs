## A7 scope contract

`classify_readability_scope(changed_paths, existing_paths)` takes the **current** existing inventory (including new files), requires every changed path to exist, and returns required checks separately from unchanged legacy candidates. The test computes changed paths by comparing current bytes to this pinned baseline, so callers cannot mark a new file legacy merely by leaving it off a supplied list. Missing baseline files and links outside the repository fail closed. Source analysis reads files only; no inspected source executes.

The two initial A7 checker files are baseline files because the queue applies this gate to files changed **after A7**. Their later changes are checked. The hash inventory must not be regenerated by future builds to hide failures. Append future reviewed legacy resolutions; never move a failing changed file into the baseline.

The writer check accepts explicit UTF-8 text/JSON/JSON Lines/CSV and SQLite paths. It rejects forbidden serialization modules, byte-write APIs, binary modes, dynamic destinations/modes, unknown named writers, unresolved streams and stream escape. It is conservative and can require review of safe dynamic code; it is not a proof of arbitrary indirect behavior. Static check failures are not bypassed by claiming AI approval.
